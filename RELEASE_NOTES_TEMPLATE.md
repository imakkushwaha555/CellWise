## Install

Download the add-in ZIP and follow the current installation instructions. The Windows EXE is a
testing-only installer for an existing writable UNC trusted catalog; Microsoft does not support
that deployment route for production.

## Verify downloads

Verify the SHA-256 checksums in `SHA256SUMS.txt`. Build provenance is attached as
`provenance.sigstore.json` and is also recorded by GitHub artifact attestations.

## Limitations

- No MSI installer is currently provided.
- Live Word, clean-VM installation, and SmartScreen behavior must be confirmed by a human tester.
