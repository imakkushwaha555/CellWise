# Security policy

Cellwise is a small Office.js add-in. The current installer and network-share registration flow are testing-only and have not been verified in a clean Windows VM or live Word.

## Reporting a concern

Do not post exploit details, document contents, credentials, or other sensitive material in a public issue. Private GitHub vulnerability reporting is not configured because the repository has not yet been created. Once a repository exists, maintainers should enable private vulnerability reporting and update this file with the exact reporting route.

If no private route is available, do not send sensitive details to a public forum. Wait for maintainers to publish a private contact method.

## Scope and response

Report issues involving Cellwise source, its build/release workflow, or its installer prototype. Include the affected version or commit and a concise impact description, but do not attach private Word documents. Response times are not guaranteed while the project has no public maintainer contact.
