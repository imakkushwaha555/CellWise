# Zenodo DOI setup guide

No Zenodo record or DOI has been created. After the GitHub repository exists and the owner is ready to publish:

1. Review Zenodo's [GitHub and software guide](https://help.zenodo.org/docs/github/) and create or sign in to a Zenodo account.
2. Connect GitHub from Zenodo and enable the intended public `cellwise` repository.
3. Confirm that the repository's license, `CITATION.cff`, version, and release notes are correct.
4. Publish a GitHub Release only after the release gate and human tests are complete.
5. Confirm that Zenodo archived the release and assigned a DOI.
6. Add the version DOI to the corresponding GitHub release and update the README badge only after checking the DOI resolves to the correct archive.

Enabling the integration and publishing a release are external account actions and require the repository owner's approval. Do not claim a DOI before Zenodo creates it.
