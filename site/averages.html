Tutorial

Calculate averages in Word tables

Cellwise's AVERAGE function accepts an A1-style range, for example =AVERAGE(C2:C6).

Host test status: live Word behavior has not yet been verified. Use a copy of your document while evaluating the testing build.

Calculate an average

  1. Choose the result cell in the same Word table.
  2. Enter =AVERAGE(C2:C6), changing the column and row range to match the cells to average.
  3. Choose Apply.
  4. After editing the input values, choose Recalculate table.

How the range is read

The top-left cell in the table is A1. A range includes numeric cells between its endpoints; empty and non-numeric cells are skipped by the current engine. Cellwise does not read cells from another table or workbook.

Related formulas

  • =SUM(C2:C6) adds the range.
  • =MIN(C2:C6) and =MAX(C2:C6) return the lowest and highest numeric values.
  • =ROUND(AVERAGE(C2:C6),2) rounds the result to two decimal places.

See the full formula reference or the A1 addressing guide.
