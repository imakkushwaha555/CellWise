Addressing guide

Word table formula cell references

Cellwise uses A1 notation based on the row and column position within the current table.

Address rules

  • The table's top-left cell is A1.
  • Columns count from left to right: A, B, through Z, then AA, AB, and onward.
  • Rows count from top to bottom, starting at 1. A header is still part of the table and therefore uses row 1.
  • References and ranges refer only to the table in which the formula is applied.

Examples

AddressPosition in the current table
A1First row, first column
B3Third row, second column
AA2Second row, twenty-seventh column
B2:B5Cells in column B, rows 2 through 5

Use a range

Use a colon between the first and last cell, as in =SUM(B2:B5). Cellwise accepts the range endpoints in either order and reads the rectangle between them. Numeric values are used; empty and non-numeric values are skipped.

For a worked example, see how to sum a Word table column.
