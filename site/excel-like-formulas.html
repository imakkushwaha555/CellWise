Formula reference

Excel-like formulas in Word tables

Cellwise provides A1-style references and a small independent formula engine for the current Word table. It is not a complete spreadsheet engine.

Functions

FunctionExamplePurpose
SUM=SUM(A1:A4)Add numeric values in a range.
AVERAGE=AVERAGE(A1:A4)Average numeric values in a range.
MIN / MAX=MAX(A1:A4)Return the lowest or highest supplied value.
COUNT=COUNT(A1:A4)Count numeric values supplied to the function.
ABS=ABS(-4)Return the absolute value.
ROUND=ROUND(10/3,2)Round to the requested number of decimal places.

Operators

Cellwise supports addition (+), subtraction (-), multiplication (*), division (/), exponentiation (^), percentage (%), and parentheses.

How it differs from Word's built-in table formulas

Word's built-in formula field already accepts spreadsheet-style table-cell references (for example, =SUM(A4:C4)) and can insert positional expressions such as =SUM(ABOVE) or =SUM(LEFT) when a formula is omitted. Cellwise is a separate task-pane workflow that stores its formula text with the result and offers an explicit table-recalculation command. Its function set and behavior are limited and different; it does not add a capability that Word's built-in field lacks, replace those fields, or promise Excel compatibility. See Microsoft's Word Selection.InsertFormula reference.

Cellwise's formula engine and Word integration have automated tests, but real-host behavior has not yet been verified. See the repository's test checklist.
