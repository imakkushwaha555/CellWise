A1 formulas for Word tables

Calculate table cells without helper rows or columns.

Cellwise adds direct A1-style cell references and a small set of formulas to tables in Microsoft Word. Formula evaluation stays in the add-in.

Why Cellwise

Word already supports spreadsheet-style references in its built-in formula fields, and can also insert positional formulas such as SUM(ABOVE) or SUM(LEFT). Cellwise offers a separate task-pane workflow for applying and recalculating its documented formula subset using table-relative addresses such as B2. Neither workflow requires visible column letters or row numbers. Cellwise is not a replacement for Excel or a promise of complete spreadsheet compatibility. See Microsoft's Word formula-field reference.

Natural cell references

Use A1, B2, AA3, or ranges such as B2:B5.

Local calculation

Cellwise has no telemetry. The add-in downloads from its configured host, but its code does not upload document contents to a Cellwise service.

Small, independent engine

Seven functions and common arithmetic operators are implemented in original TypeScript with no runtime package dependencies.

Install for testing

For local development, build and sideload the development manifest using the instructions in the repository. The Windows EXE is an unsigned testing prototype and requires an existing writable UNC share plus a hosted HTTPS add-in page. No MSI or production self-service installer is available.

Organizations can evaluate Microsoft 365 centralized deployment with an administrator. This is not a personal, no-admin install path.

Frequently asked questions

How do I use Excel-style cell references in Word tables?

Place the cursor in the destination cell, enter a formula such as =A1+B1 or =SUM(B2:B5), and choose Apply. A1 is the top-left cell of that table.

How do I sum a column in a Word table?

In the total cell, enter a range sum such as =SUM(B2:B5), changing the range to match your table rows. See the step-by-step guide.

Does Cellwise support every Excel formula?

No. It supports the listed functions and operators only. It has no workbooks, named ranges, external data connections, or full Excel compatibility.

Does my document content leave my computer?

The Cellwise code contains no telemetry or document upload. The browser or Office host downloads the add-in files from the configured HTTPS host and loads Office.js from Microsoft's official URL.
