Sum a column in a Word table

Use an A1-style range formula such as =SUM(B2:B5) in the destination cell. Cellwise calculates locally and does not require visible helper labels.

Host test status: the steps describe the implemented add-in workflow, but live Word behavior has not yet been verified. Test first with a copy of a document.

Steps

  1. Use a Word table with numeric values in the column you want to total.
  2. Click the cell where the total should appear.
  3. In Cellwise, enter a formula such as =SUM(B2:B5). Here, B2 through B5 are the cells to add; adjust the range for your table.
  4. Choose Apply. The formula result is written in the selected cell.
  5. After changing the input values, choose Recalculate table.

Example

RowAmountNote
212First value
318Second value
425Third value

To total the three displayed amounts, use =SUM(B2:B4) in the result cell. The example uses its first table row as row 1; therefore the first data row shown is row 2.

Common issues

  • Make sure the formula starts with =.
  • Check that the range refers to the same table and includes only the intended data rows.
  • Cellwise supports numeric values and its documented function subset, not every Excel formula.
  • If the result is out of date, use Recalculate table.
