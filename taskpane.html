Cellwise

Selected range: —

Functions: SUM, AVERAGE, MIN, MAX, COUNT, ABS, ROUND. Operators: + - * / ^ %

Help & support

Place the cursor in a table cell, enter a formula beginning with =, then choose Apply. Choose Recalculate table after changing input values.

The table's top-left cell is A1. Use a range such as B2:B5 to refer to cells in the same table. This add-in supports the functions and operators listed above, not every spreadsheet formula.

Formulas are evaluated locally. Cellwise does not include telemetry or send document contents to a service. See the project's testing checklist for troubleshooting.
